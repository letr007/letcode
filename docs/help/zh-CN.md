# letcode TUI 帮助手册

## 快速开始

- `Tab` 切换目录和正文。
- `↑` / `↓` 或 `k` / `j` 选择章节或滚动正文。
- `PgUp` / `PgDn` 翻页，`Home` / `End` 跳到首尾。
- `Esc` 或 `q` 关闭帮助。

宽屏同时显示目录和正文。窄屏用 `Tab` 切换。

在项目目录启动 letcode。

```sh
letcode
```

- 用 `/model` 选择已配置的模型。
- 用 `/permission` 查看权限模式。
- 输入任务后按 `Enter`。写清目标和相关文件。
- 输入 `/help` 或 `/?` 打开本手册。

输入 `/` 打开命令补全，输入 `@` 打开专家补全。
按 `↑` / `↓` 选择条目，按 `Tab` 插入。
补齐参数后再提交命令。

## 快捷键

**主会话输入**

输入区没有弹窗、提问、审批请求或补全列表时，适用以下按键。

- `Enter` 提交输入。`Shift+Enter` 插入换行。
- `←` / `→` 移动光标。`Backspace` / `Delete` 删除文字。
- `Home` / `Ctrl+A` 移到输入开头。
- `End` / `Ctrl+E` 移到输入末尾。
- `↑` / `↓` 浏览输入历史。
- `PgUp` / `PgDn` 滚动对话。`Ctrl+End` 回到对话底部。
- `Ctrl+V` / `Cmd+V`、`Alt+V` 或 `Shift+Insert` 粘贴剪贴板内容。
- `Ctrl+Backspace` 移除队尾待发消息，保留输入草稿。
- `Ctrl+T` 切换当前模型支持的推理强度。
- `Esc` 清除文字选区。没有选区时，连按两次可中断当前执行。
- `Ctrl+C` 复制选中文字。没有选区时，主回合运行中需再次按键确认中断。
  主回合空闲时，`Ctrl+C` 退出。

终端需要能识别对应组合键。
部分终端无法区分 `Ctrl+Backspace` 和普通退格。

**Ctrl+X 快捷键**

先按 `Ctrl+X`，松开后再按下一个键。
这些快捷键适用于没有弹窗、补全列表、提问或审批请求的场景。

- `b` 切换会话面板。
- `m`、`p`、`r` 和 `t` 分别打开模型、权限、推理强度和思考显示选项。
- `a`、`c`、`i` 和 `s` 打开专家模型、上下文详情、MCP 工具和技能。
- `h` 或 `?` 打开帮助。
  子视图输入为空时，`h` 浏览上一个子会话，按 `?` 打开帮助。
- 主视图中，`↓` 打开第一个子会话。`←` / `→` 浏览子会话。
- `↑` 返回父会话视图。

**弹窗和子会话**

- 选择弹窗中，`↑` / `↓` 选择条目，`Enter` 确认，`Esc` 关闭。
- 可搜索的弹窗中，输入文字筛选列表。`Backspace` 编辑筛选词。
  不可搜索的选择弹窗也支持 `k` / `j` 移动。
- 会话选择器中，`←` / `→` 切换当前工作区和全部工作区。
- 配置编辑器中，`Enter` 编辑或展开条目。
  未编辑字段时，`Ctrl+S` 保存配置草稿。
- 子视图输入为空时，`↑` 返回父会话。
  `←` / `→` 或 `h` / `l` 浏览子会话，`j` / `k` 滚动对话。
- 主输入区或子视图中，`Alt+←` / `Alt+→` 浏览子会话。
  `Alt+↑` 返回父会话。
- 提问中，`Tab` 切换页签，`↑` / `↓` 选择答案。
  `Enter` 选择或编辑答案。在确认页按 `Enter` 提交。

## 会话与上下文

对话事件写入会话日志。
`/resume` 打开选择器，`/resume <session_id>` 按 ID 或前缀恢复会话。
选择器默认列出当前工作区的会话。
恢复对话不会重新启动未完成的工具或后台进程。

`/new` 开始独立的新对话。
新建、恢复或导航会话前，先等待当前执行结束，或中断执行。
没有任务运行时，用 `/exit` 或 `/quit` 退出终端界面。

回合运行中提交的消息进入队列，并标记为 `QUEUED`。
`Ctrl+Backspace` 移除最新一条尚未派发的消息。
当前执行和输入草稿保持不变。
移除的消息仍在输入历史中，可按 `↑` 找回。

- `/context` 打开当前上下文详情。
- `/compact` 调用内部 `historian` 整理历史，减少活动上下文。
- `/tree` 打开对话历史，选择导航位置。
- `/undo` 移到上一个已完成回合。`/redo` 再向前移动。

历史导航改变对话上下文，保留已记录的历史。
它不会撤销项目文件的修改。
上下文压缩使用历史摘要，会话日志保留原始记录。

## 专家与子会话

直接委派时，在消息开头写专家名（例如 `@explorer`），后接任务。
限定任务范围，并写明预期结果。

- `@explorer` 只读探索仓库代码。
- `@fixer` 在指定写入范围内实现或修复文件。
- `@oracle` 只读分析根因、风险和验证方案。
- `@designer` 只读整理设计方案和接口决策。
- `@librarian` 只读收集文档和参考资料。
- `@general` 处理范围明确的只读辅助任务。

```text
@explorer 找出认证入口，不修改文件。
```

`fixer` 需要非空的 `owned_paths`，用于申请写锁。
`@fixer <task>` 简写只传任务文本，会因缺少负责路径被拒绝。
修改文件时，向主代理说明任务和文件范围，由主代理委派 `fixer`。

`/agents` 配置专家模型选项，不启动任务。
内部专家 `reviewer` 负责权限审查，`historian` 负责上下文整理。
这两个内部专家不能用 `@` 调用。

`/child` 切换父会话和子会话视图。
`/child first`、`/child next` 和 `/child prev` 选择要阅读的子会话。
查看子会话不会接管任务执行，也不改变当前主会话。
继续已结束的子会话，需要主代理显式接管。

主代理可用 `agent__jobs`、`agent__status`、`agent__wait`
和 `agent__cancel` 列出、查看、等待或取消任务。
只读任务可并发运行。读写范围重叠时会冲突。
冲突任务直接拒绝，不排队。子代理不能继续委派。

## 权限与设置

输入 `/permission` 或 `/perm` 查看权限模式。
追加模式名即可切换，例如 `/permission default`。

- `safe` 对普通工具调用请求批准。
- `default` 放行归类为读取或预览的调用。
  写入、命令和未知调用需要批准。网页读取和工作区外访问也需要批准。
- `auto` 沿用相同分类，将审批请求交给 `reviewer`。
  `reviewer` 可要求补充理由、请求人工批准或拒绝调用。
- `yolo` 跳过模式审批。工具范围和子代理路径限制仍然有效。

工具分类不能保证 shell 命令没有副作用。

审批请求中，`←` / `→` 选择选项，`Enter` 确认。
`y` / `o` 单次批准，`n` / `d` 拒绝。界面提供会话授权选项时可按 `a`。
等待审批时，`↑` / `↓` 或 `k` / `j` 滚动对话。
会话授权只覆盖界面显示的资源或调用范围。
切换模式会清空授权。新会话不继承授权。

- `/model` 选择已配置的模型。`/reasoning` 选择支持的推理强度。
- `/thoughts` 调整思考显示，`/tools` 调整工具输出显示。
- `/panel`、`/scrollbar` 和 `/theme` 调整界面。
- `/language en` 和 `/language zh-CN` 切换界面语言。
- `/mcp` 浏览 MCP 服务和工具。`/skill` 浏览本地技能。
- `/config` 打开配置编辑器。字段修改保存前仍是草稿。

回合运行中修改模型、权限或推理强度，会在回合结束后生效。
配置编辑器中的 `Ctrl+S` 只保存配置。
