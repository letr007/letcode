# 终端用户界面

letcode 提供基于 Ratatui 的全功能终端用户界面（TUI）。界面参考了类似 opencode 的交互风格，支持流式对话渲染、交互式工具卡片、权限审批弹窗与原生富文本图表排版。

通过以下命令启动默认 TUI 模式：

```sh
letcode
```

## 布局与组件划分

终端界面采用模块化布局：

```text
┌────────────────────────────────────────────────────────┐
│ 主对话时间线（Timeline）                                  │
│ 包含用户输入、助手回复、思考块、工具执行卡片与子代理状态        │
│                                                        │
│                                                        │
├────────────────────────────────────────────────────────┤
│ 交互输入区（多行编辑、自动换行与命令自动补全）                 │
├────────────────────────────────────────────────────────┤
│ 底部状态栏（当前模型、权限模式、后台任务指示与 Token 消耗）     │
└────────────────────────────────────────────────────────┘
```

- **时间线（Timeline）**：主视图区域，采用增量渲染展示会话流。助手输出以打字机形式动态追加，工具卡片实时展示调用状态与执行结果摘要；
- **思考块折叠**：模型的逐步思考过程（Reasoning）默认折叠为单行耗时提示，用户可展开查看详细推导过程；
- **输入面板**：支持单行快速提交与多行代码编辑，提供按键撤销与历史输入检索；
- **底部状态栏**：展示当前激活的模型名称、权限状态、后台子代理运行数量以及 Historian 上下文整理动画。

## 富文本与图表渲染

TUI 内置了针对终端环境优化的渲染引擎：

### 1. 流式 Markdown 渲染

系统解析标准的 Markdown 语法，包括各级标题、强调文本、无序列表、引用段落与代码块。代码块内置语法着色，在支持真彩色的终端中自动呈现代码高亮。

### 2. 原生数学公式渲染

系统支持解析 LaTeX 数学公式语法：

- 行内公式 `$ ... $` 与独立公式块 `$$ ... $$`；
- 通过 Unicode 数学符号集与终端排版规则，直接在终端内渲染上下标、根号、分数线、矩阵与积分求和符号。

### 3. 原生 Mermaid 图表渲染

系统能够在终端网格中直接绘制标准的 Mermaid 图表代码块：

- 支持流程图（`flowchart`）、时序图（`sequenceDiagram`）与状态图（`stateDiagram`）；
- 利用制表符与 Unicode 块字符绘制节点外框、标签文字、连线与箭头，无需依赖外部浏览器或图片工具。

## 斜杠命令

在输入框中输入斜杠 `/` 可以唤起内置控制命令：

| 命令 | 别名 | 功能说明 |
| --- | --- | --- |
| `/model` | `/m` | 打开模型选择面板，在已配置的模型列表中快速切换 |
| `/mode` | - | 切换权限模式（`safe`、`default`、`auto`、`yolo`） |
| `/compact` | - | 手动触发 Historian 对当前会话历史进行增量整理与上下文压缩 |
| `/language` | `/lang` | 切换界面显示语言（支持 `en` 英文与 `zh-CN` 简体中文） |
| `/theme` | - | 切换界面配色主题 |
| `/fast` | - | 开启或关闭快速模式（Fast Mode） |
| `/fake` | - | 开启或关闭客户端特征仿真 |

## 国际化与主题定制

### 1. 国际化切换

系统内置 English 与简体中文两套本地化语言包。用户可在运行时通过 `/language en` 或 `/language zh-CN` 即时切换界面文字，配置会自动保存并在下次启动时沿用。

### 2. 配色主题支持

系统支持通过外部 TOML 文件定义界面配色，内置多套终端配色方案。主题文件可定义前景色、背景色、高亮强调色、状态栏风格与语法着色，满足不同终端背景（深色或浅色）的阅读需求。

## 源码索引

- `src/tui/runtime.rs`：实现 TUI 事件主循环、终端初始化与键盘事件派发。
- `src/tui/timeline.rs`：管理时间线组件布局、虚拟滚动与流式文本追加。
- `src/tui/markdown.rs`：实现终端专用的流式 Markdown 解析与文本着色。
- `src/tui/math.rs`：实现基于 Unicode 的终端 LaTeX 数学公式排版引擎。
- `src/tui/mermaid/`：实现终端字符级的 Mermaid 矢量图表渲染引擎。
- `src/tui/slash.rs`：注册与分发所有 TUI 前端斜杠命令。
- `src/tui/i18n.rs`：提供多语言资源映射与动态语言切换。
- `src/tui/theme.rs`、`src/tui/theme_file.rs`：管理终端配色定义与外部主题文件加载。
